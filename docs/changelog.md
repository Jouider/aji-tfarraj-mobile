# Versions de l'app

Ce que chaque version a apporté, et ce qu'il faut savoir à son sujet. Les
notes pour les stores s'écrivent à partir d'ici (Play : 500 caractères par
langue).

## 1.1.21 (58) — à publier

- **Glisser pour revenir** (iOS) partout : la réservation depuis une émission,
  une réservation depuis Mes réservations. Voir `navigation.md`.
- **Face ID sans écran « verrouillé »** : le logo de la vidéo de lancement,
  Face ID par-dessus, un bouton discret seulement après une annulation. Voir
  `app-lock.md`.
- **Chargés publics** : le taux de présence de leurs invités sur l'accueil.
- **Images dans les notifications iOS** (Notification Service Extension). Voir
  `push-notifications.md`. Premier build signé : l'identifiant de l'extension
  est créé chez Apple.

## 1.1.20 (57) — publiée le 12/10/2026 (correctif)

- **La photo de profil s'envoie de nouveau** (cassée par la 1.1.19). Même
  défaut corrigé sur le filtre par chaîne de l'onglet Émissions.
- **Sentry** n'enregistre plus les coupures réseau. Voir `sentry.md`.
- **« Ma paie »** pour le staff payé (superviseur, chauffeur de salle,
  technique). Voir `staff-pay.md`.

## 1.1.19 (56) — App Store le 07/10/2026

Le chat avec l'équipe (support), les feuilles au-dessus de la barre d'onglets,
les retraits Wafacash sans tarif chiffré (« frais à ta charge »), l'animation
de lancement en vidéo (3 s, muette). Comprend la 1.1.18, jamais envoyée
(retraits Wafacash, changement du point de retour après l'entrée).

⚠️ A introduit le bug de la photo de profil : voir `navigation.md`.
